# Ross' Rotisserie Website

A small, static multi-page site for a rotisserie chicken restaurant. Pages are assembled from a shared layout and reusable partials, with a warm, food-forward design and accessible defaults.

## Pages
- Home: Highlights the menu and testimonials.
- Menu: Detailed offerings and an order form.
- About: Team, story, and contact form.

## Features
- Shared layout and navigation/footer includes.
- Responsive layout with mobile-friendly navigation.
- Google Fonts for brand-appropriate typography.
- Accessible focus states and skip-to-content link.

## Structure
- template.html: Base layout used by all pages.
- partials/: Shared navigation and footer markup.
- scripts/: Client-side includes and layout composition.
- styles.css: Global styling.

## Run locally
Open index.html in a browser. For include loading to work consistently, use a simple local web server.
